# বিদ্যুৎ বিল ডিরেক্টরি — Android APK ও Offline-First অ্যাপ

বিদ্যুৎ বিল ও গ্রাহকের তথ্য সহজে ট্র্যাক, ব্যাকআপ এবং পরিচালনা করার জন্য গুগল মেটেরিয়াল ডিজাইন ৩ (Material You) অনুপ্রাণিত একটি আধুনিক বাংলা অ্যান্ড্রয়েড অ্যাপ (APK)।

---

## 📱 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **সম্পূর্ণ অফলাইন সাপোর্ট ও স্বয়ংক্রিয় ক্লাউড আপলোড (Offline-First & Auto-Sync)**:
   - ইন্টারনেট সংযোগ ছাড়াও অ্যাপটি ১০০% সচল থাকে — নতুন গ্রাহক যোগ, তথ্য সম্পাদনা, বিল পরিশোধ মার্ক করা এবং গ্রাহক মুছে ফেলা সবই অফলাইনে নির্বিঘ্নে কাজ করে।
   - অফলাইনে করা প্রতিটি কাজ ফোনের লোকাল স্টোরেজে এবং **Offline Sync Queue (`billOfflineSyncQueue`)**-তে সংরক্ষিত থাকে।
   - ইন্টারনেট সংযোগ পাওয়ার সাথে সাথেই পেন্ডিং থাকা সকল কাজ স্বয়ংক্রিয়ভাবে Firebase ক্লাউডে আপলোড হয়ে যায়।

2. **একই সিগনেচারে APK তৈরি (Same Signature APK)**:
   - রিপোজিটরির `android-keystore/biddut-bill-release.p12` কী-স্টোর ব্যবহার করে প্রতিটি বিল্ডে একই ডিজিটাল সিগনেচার (`SHA1: A7:F8:FB:7B:E5:B5:E2:4F:6C:A2:43:CB:F2:E7:6F:D9:C5:0C:AE:62`) দিয়ে রিলিজ APK সাইন করা হয়।
   - এর ফলে পূর্বের অ্যাপ আনইনস্টল না করেই এবং কোনো ডেটা না হারিয়ে সরাসরি নতুন আপডেট ইনস্টল করা যায়।

3. **স্বয়ংক্রিয় ভার্সন বৃদ্ধি (Auto-Incrementing Version)**:
   - আপনাকে কখনোই ম্যানুয়ালি ভার্সন নম্বর পরিবর্তন করতে হবে না।
   - GitHub-এ কোড পুশ করার সাথে সাথেই `github.run_number` অনুযায়ী স্বয়ংক্রিয়ভাবে `versionCode` (`100 + run_number`) এবং `versionName` (`2.0.<run_number>`) বৃদ্ধি পায়।

4. **GitHub Push করলেই স্বয়ংক্রিয় APK বিল্ড ও Release প্রকাশ**:
   - `.github/workflows/build-apk.yml` ওয়ার্কফ্লো প্রতিটি `main`/`master` ব্রাঞ্চ পুশে স্বয়ংক্রিয়ভাবে অ্যাকশন রান করে।
   - বিল্ড শেষে রিপোজিটরির **Releases** অপশনে নতুন ট্যাগ (`v2.0.x`) তৈরি করে সেখানে স্বাক্ষরিত `.apk` ফাইল (`Biddut-Bill-v2.0.x.apk` এবং `Biddut-Bill-latest.apk`) আপলোড করে দেয়।

5. **অ্যাপের ভেতর অটো-আপডেট নোটিফিকেশন ও ইন-অ্যাপ আপডেট**:
   - অ্যাপ চালু হলে বা ইন্টারনেট সংযোগ পেলে অ্যাপটি স্বয়ংক্রিয়ভাবে GitHub Releases এবং `version.json` চেক করে।
   - নতুন ভার্সন পাওয়া গেলে অ্যাপের ভেতরেই আপডেট নোটিফিকেশন ব্যানার ও ডায়ালগ দেখায় এবং এক ক্লিকে অ্যাপের ভেতর থেকেই নতুন APK ডাউনলোড ও আপডেট করা যায়।

6. **নিখুঁত APK লোগো (Adaptive & Standard Launcher Icons)**:
   - `scripts/setup-android-apk.mjs` স্ক্রিপ্টের মাধ্যমে `public/icon.png` এবং `public/pwa-maskable-512x512.png` লোগোটি স্বয়ংক্রিয়ভাবে অ্যান্ড্রয়েডের সকল `mipmap-*` ফোল্ডারে (`ic_launcher.png`, `ic_launcher_round.png`, `ic_launcher_foreground.png`) যুক্ত হয়।

---

## 🚀 GitHub এর মাধ্যমে APK রিলিজ পাওয়ার নিয়ম

১. আপনার কোড GitHub রিপোজিটরির `main` বা `master` ব্রাঞ্চে `git push` করুন।
২. রিপোজিটরির **Actions** ট্যাবে গেলে দেখবেন **"Build Signed APK & Publish GitHub Release"** ওয়ার্কফ্লোটি স্বয়ংক্রিয়ভাবে চালু হয়েছে।
৩. বিল্ড সম্পন্ন হলে রিপোজিটরির ডান পাশের **Releases** সেকশনে নতুন ভার্সনের APK ফাইলটি ডাউনলোডের জন্য প্রস্তুত হয়ে যাবে এবং ইনস্টল থাকা অ্যাপে স্বয়ংক্রিয়ভাবে আপডেট নোটিফিকেশন চলে যাবে।
