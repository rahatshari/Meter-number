# বিদ্যুৎ বিল ডিরেক্টরি — Modern Material You (MD3) App

বিদ্যুৎ বিল ও গ্রাহকের তথ্য সহজে ট্র্যাক, ব্যাকআপ এবং পরিচালনা করার জন্য গুগল মেটেরিয়াল ডিজাইন ৩ (Material You) অনুপ্রাণিত একটি আধুনিক বাংলা মোবাইল অ্যাপ।

---

## 📱 প্রধান বৈশিষ্ট্যসমূহ (Features)

1. **গুগল মেটেরিয়াল ডিজাইন ৩ (Material You) ইউজার এক্সপেরিয়েন্স**:
   - অ্যান্ড্রয়েড-নেটিভ লুক ও ফিল, টোনাল কালার প্যালেট, সফট রাউন্ডেড কার্ড এবং নিখুঁত টাচ রেসপন্স।
   - **লাইট ও ডার্ক থিম**: স্বয়ংক্রিয় সিস্টেম ডিটেকশন এবং ওয়ান-ট্যাপ থিম টগল (লোকাল স্টোরেজে সংরক্ষিত থাকে)।
   - **৪-ডেস্টিনেশন বটম নেভিগেশন বার**: হোম (ড্যাশবোর্ড), গ্রাহক (ডিরেক্টরি), বকেয়া (বকেয়া খাতা), সেটিংস (ব্যাকআপ ও ক্লাউড)।

2. **লাইভ ড্যাশবোর্ড ও KPI মেট্রিক্স**:
   - **মোট গ্রাহক**, **বিল পরিশোধিত**, **বিল বকেয়া**, এবং **জরুরি বকেয়া** (সময় শেষ বা আজকের মধ্যে বাকি) সরাসরি লাইভ ডেটা থেকে রিয়েলটাইমে প্রদর্শিত হয়।
   - জরুরি বকেয়া অ্যালার্ট ব্যানার এবং তাৎক্ষণিক অ্যাকশন স্ট্রিপ।

3. **গ্রাহক ডিরেক্টরি ও অনুসন্ধান**:
   - নাম, মোবাইল নম্বর, SMS অ্যাকাউন্ট / মিটার নম্বর বা ঠিকানা দিয়ে ইনস্ট্যান্ট সার্চ ও ক্লিয়ার বাটন।
   - মেটেরিয়াল ৩ ফিল্টার চিপস: **সব গ্রাহক**, **বাকি আছে**, **পরিশোধিত**।
   - বিলের শেষ তারিখ অনুযায়ী নির্দিষ্ট ড্রপডাউন চিপ।

4. **স্মার্ট কাউন্টডাউন ও ১-ট্যাপ কপি**:
   - ১-৩১ তারিখের বিল পরিশোধের শেষ সময় হিসাব করে আর কত দিন ও ঘণ্টা বাকি বা সময় শেষ তা ডায়নামিক স্ট্যাটাস পিল দ্বারা প্রদর্শন।
   - এক ক্লিকে মোবাইল নম্বর ও ১৩ ডিজিটের SMS অ্যাকাউন্ট নম্বর ক্লিপবোর্ডে কপি করার সুবিধা (ভিজ্যুয়াল ফিডব্যাক সহ)।

5. **নিখুঁত গ্রাহক যোগ ও সম্পাদনা**:
   - মেটেরিয়াল আউটলাইন্ড টেক্সট ফিল্ড ও হেল্পার টেক্সট।
   - ১১ ডিজিটের মোবাইল নম্বর ভ্যালিডেশন।
   - ১৩ ডিজিটের SMS অ্যাকাউন্ট / মিটার নম্বর ভ্যালিডেশন এবং একই SMS নম্বর অন্য গ্রাহকে ডুপ্লিকেট হওয়া রোধের সুরক্ষা।
   - ১ থেকে ৩১ এর মধ্যে বিলের শেষ তারিখ যাচাইকরণ।

6. **বকেয়া খাতা ও হোয়াটসঅ্যাপ সামারি**:
   - চলতি মাসে যাদের বিল বাকি তাদের নিয়ে ফোকাসড বকেয়া তালিকা।
   - এক ক্লিকে হোয়াটসঅ্যাপ বা মেসেজে পাঠানোর উপযোগী পূর্ণাঙ্গ বকেয়া সামারি টেক্সট কপি।

7. **ডেটা হাব, ব্যাকআপ ও ক্লাউড সিঙ্ক**:
   - **Google ক্লাউড সিঙ্ক**: Google একাউন্টে লগইন করে সকল ডিভাইসে রিয়েল-টাইম ব্যাকআপ ও অটো-সিঙ্ক।
   - **JSON ব্যাকআপ**: সম্পূর্ণ ডেটা এক্সপোর্ট ও ডাউনলোড, ড্র্যাগ-অ্যান্ড-ড্রপ ইমপোর্ট এবং স্মার্ট মার্জ (Smart Merge) বা সম্পূর্ণ প্রতিস্থাপন (Replace All)।
   - **Excel / CSV স্প্রেডশিট**: বাংলা ফন্ট সাপোর্ট সহ UTF-8 BOM যুক্ত `.csv` স্প্রেডশিট ডাউনলোড।
   - **অফলাইন মোড**: ইন্টারনেট না থাকলেও ব্রাউজারের লোকাল স্টোরেজে নিরবচ্ছিন্ন কার্যক্ষমতা।

## 🛠️ প্রযুক্তি (Tech Stack)

- **Framework**: React 19 + TypeScript + Vite
- **Design System**: Material Design 3 (Material You) Tokens & Tonal Surfaces
- **Styling**: Tailwind CSS & Material CSS Custom Properties
- **Database & Auth**: Firebase Firestore (Realtime `onSnapshot`) & Firebase Authentication
- **Typography**: Google Fonts — Noto Sans Bengali

---

## 💻 লোকালি রান করার নিয়ম (Run Locally)

```bash
# ডিপেন্ডেন্সি ইন্সটল
npm install

# ডেভেলপমেন্ট সার্ভার চালু (পোর্টে ৩০00)
npm run dev
```

## 🚀 GitHub Pages-এ ডিপ্লয় করার নিয়ম (Deploy to GitHub Pages)

অ্যাপটিতে `vite.config.ts`-এ `base: './'` কনফিগার করা আছে, যার ফলে এটি সাব-ডিরেক্টরিতেও (যেমন: `https://rahatshari.github.io/Meter-number/`) নির্বিঘ্নে কাজ করে।

### পদ্ধতি ১: GitHub Actions অটোমেশন (সুপারিশকৃত ও সম্পূর্ণ প্রস্তুত)
রিপোসিটরিতে ইতোমধ্যে `.github/workflows/deploy.yml` ফাইলটি যুক্ত ও কনফিগার করা আছে।
১. আপনার GitHub রিপোজিটরির **Settings** ট্যাবে যান।
২. বাম পাশের মেনু থেকে **Pages**-এ ক্লিক করুন।
৩. **Build and deployment** সেকশনের **Source** ড্রপডাউনে **"GitHub Actions"** সিলেক্ট করুন।
৪. ব্যস! এবার `main` বা `master` ব্রাঞ্চে পুশ করলে স্বয়ংক্রিয়ভাবে বিল্ড হয়ে অ্যাপ লাইভ হয়ে যাবে।

### পদ্ধতি ২: সরাসরি কমান্ড দিয়ে ডিপ্লয় (gh-pages)
রিপোসিটরিতে `gh-pages` প্যাকেজ ও স্ক্রিপ্ট কনফিগার করা আছে:
```bash
npm run deploy
```
এই একটি কমান্ড চালালেই প্রোডাকশন বান্ডেল বিল্ড হয়ে `gh-pages` ব্রাঞ্চে স্বয়ংক্রিয়ভাবে ডিপ্লয় হয়ে যাবে।
